Privacy Policy – Tech Aasan Uploader

Last updated: 11 November 2026

Tech Aasan Uploader is used only by the owner of the Tech Aasan YouTube channel to manage that channel. It uses Google OAuth to access the owner's own YouTube account in order to upload videos, set thumbnails, reply to comments on the channel's own videos and read the channel's own analytics.

Data accessed through YouTube API Services is stored only on the owner's own computer, is not sold or shared with third parties, and is used only for the purposes above. Public comment text is read only to reply to it. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).

You can revoke access at any time at https://myaccount.google.com/permissions.
